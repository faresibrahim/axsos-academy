1. First: what is this?

In JavaScript, this is a special keyword that refers to an object, depending on how a function is called.

For now, think of it as:

this = "the object I'm currently working with."

Example:

const user = {
  name: "Fares",

  sayName: function () {
    console.log(this.name);
  }
};

user.sayName();

Output:

Fares

Here, this refers to user.

So:

this.name

is basically:

user.name
2. What does this mean when passed as an argument?

This is the important part.

You can pass this to another function just like you can pass any other value.

const user = {
  name: "Fares",

  sayName: function () {
    printName(this);
  }
};

function printName(person) {
  console.log(person.name);
}

user.sayName();

Output:

Fares

What's happening?

Step 1

We call:

user.sayName();

Inside sayName, this refers to user.

So this:

printName(this);

is effectively:

printName(user);
Step 2

printName() receives that object:

function printName(person) {
  console.log(person.name);
}

So:

person

is now referring to the same object as user.

Therefore:

person.name

gives us:

Fares
3. this is just being passed as a value

This is a useful way to think about it:

function showPerson(person) {
  console.log(person);
}

const user = {
  name: "Fares"
};

showPerson(user);

We're passing the user object.

When you do:

showPerson(this);

you're saying:

"Pass whatever this currently refers to into this function."

5. You can pass this along with other arguments
const user = {
  name: "Fares",

  greet: function (message) {
    sendMessage(this, message);
  }
};

function sendMessage(person, message) {
  console.log(person.name + ": " + message);

Output:

Fares: Hello!

Here:

sendMessage(this, message);

passes two things:

this     → the user object
message  → "Hello!"

So it's basically:

sendMessage(user, "Hello!");

7. One important distinction

Don't confuse these two:

print(this);

and:

print(this.name);

The first passes the entire object:

print(user);

The second passes only the name:

print("Fares");

For example:

const user = {
  name: "Fares",

  test: function () {
    console.log(this);
    console.log(this.name);
  }
};

user.test();

The first console.log shows the object.

The second shows:

Fares

So the mental model I want you to keep for now is:

this
 ↓
current object
 ↓
pass it to another function
 ↓
that function receives the object as a parameter

For example:

function otherFunction(object) {
    console.log(object.name);
}

const user = {
    name: "Fares",

    test: function () {
        otherFunction(this);
    }
};

this isn't magically connected to object. You're simply passing the value that this refers to.
