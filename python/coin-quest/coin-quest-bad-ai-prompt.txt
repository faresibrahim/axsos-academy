The main bug is in Hero.collect(): you're using self.coins, but the coins are stored in self.backpack.coins.

Here's the fixed code:

class Backpack:
    def __init__(self, owner, coins=0):
        self.owner = owner
        self.coins = coins

    def add_coins(self, amount):
        self.coins += amount

    def spend_coins(self, amount):
        if self.coins >= amount:
            self.coins -= amount
        else:
            print('Not enough coins')
        return self

    def display(self):
        print(f"{self.owner}'s backpack has {self.coins} coins")
        return self


class Hero:
    def __init__(self, name):
        self.name = name
        self.backpack = Backpack(name)

    def collect(self, amount):
        self.backpack.add_coins(amount)
        return self

    def buy_item(self, amount):
        self.backpack.spend_coins(amount)
        return self

    def gift_coins(self, other_hero, amount):
        if self.backpack.coins >= amount:
            self.backpack.spend_coins(amount)
            other_hero.backpack.add_coins(amount)
        else:
            print('Not enough coins to gift')
        return self


hero1 = Hero('Lina')
hero2 = Hero('Omar')

hero1.collect(50).buy_item(15).gift_coins(hero2, 20)

hero1.backpack.display()
hero2.backpack.display()

Expected output
Lina's backpack has 15 coins
Omar's backpack has 20 coins
What was fixed?
collect() — Changed self.coins += amount to self.backpack.add_coins(amount), because the coins belong to the backpack.

gift_coins() — Deducted the gifted coins from Lina before adding them to Omar. Your original code only added coins to Omar, effectively creating coins out of nowhere.

Insufficient funds — Added a message if Lina cannot afford to gift the requested amount.

Key concept: self.backpack is an object of the Backpack class. To access its attributes or methods, use self.backpack.coins or self.backpack.add_coins(amount).

The return self statements allow method chaining, which is why you can write:

hero1.collect(50).buy_item(15).gift_coins(hero2, 20)

Each method returns the same Hero object, allowing the next method to run on it.
